# NumPy Notes 📘

A collection of my personal notes, practice problems, and code snippets while learning **NumPy** — the core library for numerical computing in Python.

## 📂 What's Inside

This repo contains Jupyter notebooks covering:

- NumPy array basics (creation, indexing, slicing)
- Array operations (arithmetic, broadcasting, reshaping)
- Aggregation functions (sum, mean, min, max, std, etc.)
- Random number generation
- Linear algebra basics with NumPy
- Practice problems and solved exercises

## 🛠️ Tools Used

- Python
- NumPy
- Jupyter Notebook / Google Colab

## 🚀 How to Use

1. Clone this repo:
   ```
   git clone https://github.com/stereoxyz/Numpynotes.git
   ```
2. Open any `.ipynb` file in Jupyter Notebook or upload it to Google Colab.
3. Run the cells to see the code and explanations in action.

This repo is mainly for my own learning and reference, but feel free to explore it if you're also learning NumPy — contributions, suggestions, or corrections are welcome!
